# Wrist D405 Perceived World Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** cuRobo's collision world fed by the wrist-mounted RealSense D405
— no extrinsic calibration (the camera rides TF), obstacles persist when
the wrist looks away, and frames captured mid-motion can't smear the map.

**Architecture:** Two surgical upgrades to the existing pipeline. (1)
Frustum-aware decay in `VoxelAccumulator`: a voxel loses confidence ONLY
when the camera provably sees through its location (projects into the
frame, in range, measured surface behind it); everything out of view is
remembered. Pure helper `visible_free_cells()` computes the decayable
set. (2) The cameras node looks up the camera pose **at each depth
frame's timestamp** and drops frames taken while the camera was moving
faster than a threshold. Default camera becomes the D405; the Orbbec path
stays supported but dormant (its config file doesn't exist until someone
calibrates one).

**Tech Stack:** numpy (core, offline-tested), rclpy/tf2 (node), existing
`realsense2_camera` apt driver. No cuRobo/planner changes.

**Spec:** `docs/superpowers/specs/2026-08-17-perceived-world-design.md`
(stage 2), amended by this header per user pivot 2026-08-18 (Orbbec
dropped; D405 is the primary and only camera).

## Global Constraints

- core = NO ROS imports; scipy stays lazily imported.
- D405 range clip 0.07–0.9 m comes from the camera YAML (short-range

- The un-viewed world is never decayed; the ignore region and baseline

    set is given, only non-hit voxels IN that set decay.

Extend `VoxelAccumulator.update` (replace the decay loop):

```python
    def update(self, points, min_points_per_voxel=2, decay_cells=None):
        hit = set()
        if len(points):
            idx = np.floor(np.asarray(points) / self.voxel).astype(np.int64)
            uniq, counts = np.unique(idx, axis=0, return_counts=True)
            hit = set(map(tuple, uniq[counts >= int(min_points_per_voxel)]))
        for c in hit:
            self._scores[c] = min(self._scores.get(c, 0) + 1, self.max_score)
        # decay_cells scopes forgetting for narrow-FOV / moving cameras:
        # only voxels the camera PROVABLY saw through may lose confidence
        # (None = legacy fixed-camera behavior: decay everything unseen).
        for c in [c for c in self._scores if c not in hit]:
            if decay_cells is not None and c not in decay_cells:
                continue
            s = self._scores[c] - 1
            if s <= 0:
                del self._scores[c]
            else:
                self._scores[c] = s
```

Add after `in_box_mask`:

```python
def visible_free_cells(
    cells,
    voxel,
    rot,
    trans,
    depth,
    fx,
    fy,
    cx,
    cy,
    min_range=0.07,
    max_range=0.9,
    margin=0.05,
):
    """Voxel cells this camera frame proves EMPTY (safe to decay).

    A cell is decayable only when the camera saw THROUGH its center: it
    projects inside the frame, its camera-frame depth is within sensor
    range, the measured pixel is valid, and the measured surface lies at
    least `margin` BEHIND the cell. Occluded, out-of-view, out-of-range,
    and depth-hole cells are all 'unknown' — never decayed. rot/trans are
    base_T_camera (the same convention transform_points uses).
    """
    cells = np.asarray(cells, dtype=np.int64).reshape(-1, 3)
    if not len(cells):
        return set()
    centers = (cells + 0.5) * float(voxel)
    r = np.asarray(rot, dtype=float)
    p_cam = (centers - np.asarray(trans, dtype=float)) @ r  # R.T @ (p - t)
    z = p_cam[:, 2]
    h, w = depth.shape
    with np.errstate(divide="ignore", invalid="ignore"):
        u = np.where(z > 0, fx * p_cam[:, 0] / z + cx, -1.0)
        v = np.where(z > 0, fy * p_cam[:, 1] / z + cy, -1.0)
    ui = np.round(u).astype(np.int64)
    vi = np.round(v).astype(np.int64)
    in_view = (
        (z > float(min_range))
        & (z < float(max_range))
        & (ui >= 0)
        & (ui < w)
        & (vi >= 0)
        & (vi < h)
    )
    free = np.zeros(len(cells), dtype=bool)
    if in_view.any():
        d = depth[vi[in_view], ui[in_view]]
        valid = (d > 0.05) & np.isfinite(d)
        free_in_view = valid & (z[in_view] < d - float(margin))
        free[np.flatnonzero(in_view)[free_in_view]] = True
    return set(map(tuple, cells[free]))
```

```python
def decayable_cells(cells, voxel, frames):
    """Union of every camera's provably-empty voxel set this tick."""
    out = set()
    for rot, trans, depth, intr, min_range, max_range in frames:
        out |= visible_free_cells(
            cells,
            voxel,
            rot,
            trans,
            depth,
            intr["fx"],
            intr["fy"],
            intr["cx"],
            intr["cy"],
            min_range=min_range,
            max_range=max_range,
        )
    return out
```
